## Goal
A finished 7-stage `DspPipeline` that meets the performance contract. It's backed by real-voice fixtures, a golden regression suite that catches sound changes, and an offline WAV tool developers use to listen.

## Steps
- [ ] Confirm all stubs are replaced. Check the order, the shared `StageMeters` → `AudioTelemetryFrame` mapping, and that `latency_samples()` = Σ stage latencies.
- [ ] Bypass dry path uses the same total latency; verify A/B is time-aligned (cross-correlation peak at 0 lag).
- [ ] Fixtures (`tests/fixtures/`, each ≤ 1 MB, 48 kHz mono FLAC, with provenance and licence for each file in `README.md`), per D-016:

  | Fixture | Source |
  | :--- | :--- |
  | `dynamic_speech`, `noisy_quiet`, `sibilant`, `plosive`, `clipping` | Self-recorded on the maintainer's **dynamic mic** with `tine-devhost record-raw` (T12), following the recording script below |
  | `headset_speech` | Self-recorded on the **gaming headset**, same script |
  | `condenser_speech` | Public-domain LibriVox excerpt (proxy; note reader, book, URL) |
  | `laptop_speech` | CC0 Mozilla Common Voice clip(s) chosen for laptop-like sound (note clip IDs) |
  | `laptop_simulated` | Clean `dynamic_speech` convolved with a CC0 room impulse response, plus CC0 fan/keyboard noise at −45 dBFS; generated by `examples/make_fixture.rs` so it's reproducible |

  Synthetic signals (sweeps, noise, impulses) are generated at test time, not stored.
  If T12 isn't done yet, record with any tool that saves raw 48 kHz WAV (e.g. Audacity on WASAPI, Windows enhancements off), then convert to FLAC.
- [ ] `golden.rs`: process every fixture with neutral params and with each stage on its own. Store **metrics**, not audio, in `tests/golden/*.json`: peak, RMS, crest, 32-band spectrum, GR stats. Compare with tolerances (±0.5 dB). `UPDATE_GOLDEN=1` regenerates them, and the reviewer must accept the diff.
- [ ] `examples/process_wav.rs` (`std` feature): `process_wav in.wav out.wav [--params file.json] [--set comp_ratio=4]...`; mono-izes stereo input, resamples nothing (it runs at the file's rate), prints latency and meters.
- [ ] Perf gate: the bench's full chain at 48 kHz and 44.1 kHz must be < 150 µs per 480 samples (CI nightly gate from T05). Record actual numbers and a per-stage breakdown. If > 60 µs, profile (`cargo flamegraph` / WPA) and note the hotspots in `## Result`.
- [ ] Long-run stability test: 10 minutes of pink noise + speech loop at random block sizes and random param changes every 100 ms. Pass criteria: no NaN, no latch, output ≤ ceiling, zero allocations.

### Recording script
Record each take at 48 kHz, mono, with **no processing** (Windows enhancements off; Discord and other voice apps closed). Use the mic's normal distance and gain.
1. `noisy_quiet`: 3 s silence in your normal room (fan/PC on), then read sentence A **quietly**, 30 cm further back than usual.
2. `dynamic_speech` / `headset_speech`: 15 s of sentences A–C at normal voice.
3. `sibilant`: "She sells sixty-six silk scarves; Sister Susie is sewing shirts for soldiers."
4. `plosive`: "Peter Piper picked a peck of pickled peppers; Bobby brought back big blue balloons." (close to the mic)
5. `clipping`: one short loud laugh or shout with gain raised until it clips.

Sentences: A "The quick brown fox jumps over the lazy dog near the riverbank." · B "Please call Stella and ask her to bring these things from the store." · C "Testing one, two, three — this is how I normally sound on voice chat."

## Acceptance criteria
- All golden tests pass; long-run stability passes.
- Full chain bench < 150 µs (hard); actual number recorded.
- `process_wav` output on every speech fixture: peaks ≤ −1 dBFS; listening notes recorded by a human reviewer in `## Result`.
- Added latency at 48 kHz ≤ 552 samples (11.5 ms), and it matches `latency_samples()`.

## Verification
```bash
cargo nextest run -p tine-dsp
cargo bench -p tine-dsp --profile perf --bench pipeline
cargo run -p tine-dsp --profile perf --example process_wav -- crates/tine-dsp/tests/fixtures/headset_speech.flac target/headset_out.wav
```

## Out of scope
Archetype presets (T10).

## Pitfalls
- If the self-recorded takes aren't ready yet, land with synthetic and public-domain/CC0 speech and leave a follow-up issue. Don't block the lane.
- Don't commit takes with other people audible in the background: fixtures are published under the repo's license.
- Check each LibriVox / Common Voice clip's licence page at download time and record the URL.
